# NGRV 4 implementation plan

**Goal:** Ship the approved build CLI plus Node.js OpenTelemetry resource detector
as version 4.0.0.

**Architecture:** Capture once during the build, package the artifact, then read
it during SDK resource detection. Prefer existing OTel attribute names; make
custom build attributes opt-in.

**Spec:** `docs/superpowers/specs/2026-09-24-ngrv-v4-design.md`

not modify the parent worktree. Existing incomplete integration work is copied
into `/Users/thilllon/git/ngrv-v4`, branch `feat/ngrv-v4-otel-detector`.
