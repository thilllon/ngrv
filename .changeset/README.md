# Changesets

Run `pnpm changeset` for publishable changes. Select `ngrv`, choose the appropriate
bump and describe the user-facing behavior. Repository-only documentation and
maintenance changes do not need a Changeset.

Changesets combines pending entries into one release using the strongest bump.
Versions and changelogs are generated by the release workflow; do not edit versions
manually. See [release automation](../docs/releases.md).
